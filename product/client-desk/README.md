# Client Desk · Design / Web Studio

Supporting documents for the Notion workspace: brief → scope → delivery → change approval → payment tracking → handoff.

Start with **BUYER-GUIDE.md**. The workspace contains the reusable **Design / Web project** and **Change request** database templates. The project template is the default for Projects and includes the six-section kit, project-scoped Change desk, deliveries and invoice views.

`project-template.html` is an editable document copy. It does not contain Notion databases, live relations or automations. Access to the working Notion template is provided separately through the seller's duplication link.

Brand assets and desktop previews are included in the supporting archive. The examples are fictional starter material. Nothing sends messages, signs agreements, changes deadlines, sends invoices or records payments automatically.
